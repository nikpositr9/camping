# CAMPORA — HTML-прототип

Чистые HTML, CSS и JavaScript. Главная — index.html, каталог — catalog.html.
Просмотр адаптива на 390, 768 и 1440 px — preview.html.

Реализовано: адаптивная сетка (в том числе 2 товара в ряд на телефоне), фильтры, описания товаров, сохраняемая корзина, количество/удаление, скачивание черновика заказа, мобильное меню, 6 FAQ, согласие, ссылки на проекты юридических страниц.

## Данные до запуска
В assets/config.js предусмотрены phone, email, viber, telegram, leadEndpoint, installationMinutes и videoUrl. Пока контакты не предоставлены, кнопки честно показывают сообщение об отсутствии данных. Отправка формы отключена без leadEndpoint. Не добавляйте секретные токены в публичные файлы.

Фото и цены демонстрационные. Правовые страницы — явно помеченные проекты, не действующая оферта. Онлайн-оплата не подключена. Видео не предоставлено, кнопка воспроизведения открывает обозначенную инструкцию, а не фиктивный видеоплеер. Поле videoUrl подключает реальный ролик с управлением воспроизведением; без видео остаётся инструкция.

Для запуска продаж нужно: утвердить товары, цены и условия; добавить реальные контакты; подключить серверную отправку и проверить получение; утвердить юридические документы; подключить оплату отдельным этапом. noindex установлен намеренно для прототипа.

Корзина сохраняет только ID товаров и количество в localStorage. Персональные данные не сохраняются в браузерном хранилище. Черновик заказа скачивается по явному действию и не отправляется продавцу.

Исходные фотографии предыдущей версии сохранены. Рабочая страница использует оптимизированные файлы assets/v5.
